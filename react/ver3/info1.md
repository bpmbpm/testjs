## 1

Мы реализовали загрузку конфигурации из внешнего файла `config.js` (в формате, совместимом с YAML) и автоматическую загрузку SVG-файлов по указанному в конфиге пути. Теперь при старте приложение пытается загрузить `config.js`, а затем – список SVG-файлов из папки, указанной в конфиге. Весь процесс автоматизирован, выбор папки вручную больше не требуется.

**Важное замечание:** Загрузка файлов с удалённого сервера (например, с GitHub) без участия пользователя возможна **только если сервер настроен на отдачу файлов с правильными CORS-заголовками**. GitHub Pages такие заголовки не добавляет, поэтому при попытке загрузить файлы с `raw.githubusercontent.com` вы получите ошибку CORS. Чтобы обойти это ограничение, мы добавили **два режима работы**:

1. **Автоматический (через `fetch`)** – если файлы доступны по прямой ссылке и сервер отдаёт CORS-заголовки.
2. **Ручной (через выбор файлов)** – если автоматическая загрузка не удалась, пользователь может вручную выбрать нужные SVG-файлы через диалог.

## Как это работает

1. **Загрузка конфига**: при старте страница динамически подгружает `config.js`, который определяет путь к SVG-файлам и их список.
2. **Автоматическая загрузка**: если в конфиге указан список файлов, приложение пытается загрузить их по URL через `fetch`.
3. **Обработка CORS**: если загрузка по URL не удалась (например, из-за CORS), приложение автоматически переключается в **ручной режим** — пользователь может выбрать файлы с диска.
4. **Логирование**: все действия (выбор файла, раскрытие/сворачивание узлов, загрузка) записываются в лог.
5. **Отображение**: при выборе файла его SVG отображается в окне диаграммы, а свойства извлекаются из содержимого.

## Важно о CORS

Если вы используете файлы с `raw.githubusercontent.com`, браузер заблокирует их загрузку из-за политики CORS. В этом случае приложение переключится в ручной режим, и вы сможете выбрать файлы с диска. Чтобы автоматическая загрузка работала, файлы должны находиться на сервере, который отдаёт правильные CORS-заголовки (например, `Access-Control-Allow-Origin: *`).
