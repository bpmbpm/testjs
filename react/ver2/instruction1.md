# Инструкция по работе с VAD-просмотрщиком

## 1. Группы функций в коде

### Группа 1: Утилиты для парсинга SVG
- `extractStagesFromSVG(svgText)` – анализирует SVG и извлекает названия этапов из текстовых элементов (игнорирует заголовок и подпись).
- `extractPropertiesFromSVG(svgText)` – формирует объект свойств (количество этапов, их список, длительность и т.д.) на основе извлечённых этапов.

### Группа 2: Управление состоянием (Reducer)
- Определены все действия: `SELECT_FILE`, `CLICK_DIAGRAM`, `CLEAR_ERROR`, `LOG`, `ADD_FOLDER`, `ADD_FILE`, `DELETE_NODE`, `EXPAND_ALL`, `COLLAPSE_ALL`, `SET_EXPANDED`, `LOAD_SVG`.
- `appReducer` – описывает все переходы состояний (`NO_SELECTION`, `FILE_SELECTED`, `ERROR_NO_SELECTION`).
- Начальное состояние создаёт дерево с папками `file1` и `file2`, внутри которых файлы `file1-1`, `file1-2`, `file2-1` (без содержимого).

### Группа 3: React-компоненты
- `TreeViewComponent` – отображение дерева с панелью инструментов (поиск, создание папки, добавление файла, удаление, развернуть/свернуть).
- `PropertiesComponent` – показывает свойства выбранного узла.
- `DiagramComponent` – отображает SVG-диаграмму.
- `LogComponent` – лог действий.
- `ToastMessage` – всплывающее сообщение об ошибке.
- `App` – корневой компонент.

### Группа 4: Инициализация
- `initApp()` – монтирует приложение в DOM и выводит сообщение в консоль.

---

## 2. Порядок работы

1. Сохраните пять SVG-файлов (их содержимое приведено выше) в любую папку на диске (например, `svg`).
2. Откройте `index.html` в браузере.
3. В дереве слева вы увидите папки `file1` и `file2`, внутри них файлы `file1-1`, `file1-2`, `file2-1`. Они помечены значком ⬇️ (не загружены).
4. **Кликните на любой файл** – откроется диалог выбора файла. Выберите соответствующий SVG-файл с диска. После загрузки:
   - справа отобразится диаграмма,
   - в окне свойств появятся извлечённые параметры (количество этапов, их список и т.д.),
   - статус узла сменится на ✅.
5. Вы можете добавлять новые папки и файлы через кнопки на панели инструментов, удалять узлы, искать по имени, управлять развёрнутостью.

## 3. Добавление функций к окнам

### TreeView
- **Поиск** – фильтрует узлы по имени (регистронезависимо). Логика в `hasMatchInSubtree`.
- **Добавление файла** – кнопка «Добавить файл» открывает диалог выбора SVG. Имя файла берётся из имени загружаемого файла.
- **Добавление папки** – запрашивает имя и создаёт папку в корне.
- **Удаление** – удаляет выбранный узел и всех потомков (с подтверждением).

### Properties
- Свойства генерируются из SVG. Чтобы изменить набор полей, отредактируйте `extractPropertiesFromSVG`.

### Diagram
- При клике на область диаграммы, если файл не выбран, показывается ошибка «Не выбран элемент treeview».
- Если файл выбран, но не загружен, можно инициировать загрузку (но в текущей версии загрузка происходит автоматически при выборе узла).

### Log
- Логируются все действия: выбор, загрузка, добавление, удаление, поиск.

---

## 4. Управление свёрнутостью
- Начальное состояние `expandedIds` содержит `root`, `file1`, `file2` (все папки развёрнуты).
- Кнопки «Развернуть всё» / «Свернуть всё» изменяют это множество.
- Для изменения начального состояния отредактируйте `INITIAL_STATE.expandedIds`.

---

## 5. Рекомендации по разработке

- **Хранение данных** – сейчас данные хранятся в памяти. Для постоянного сохранения используйте `localStorage` или `IndexedDB`.
- **Загрузка без диалога** – если файлы доступны по URL, можно загружать их автоматически через `fetch`, но это потребует сервера или политики CORS.
- **Безопасность** – при встраивании SVG из внешних источников используйте санитизацию (DOMPurify).
- **Расширяемость** – для поддержки других форматов (PNG, PDF) измените логику в `DiagramComponent` и `extractPropertiesFromSVG`.
- **Тестирование** – вынесите парсеры в отдельные модули для юнит-тестов.
- **Производительность** – при большом дереве используйте виртуализацию списка.

## 6. Примечание о загрузке файлов
- Все загрузки выполняются через `FileReader`, поэтому **не возникает проблем CORS** – файлы читаются локально после явного выбора пользователем.
- Программа не требует сервера и полностью автономна. Работа без сервера – все операции выполняются локально, без CORS-проблем, через File API.
